Learning Objectives: #

By the end of this lesson, you will be able to:

  1. Use demonstrative adjectives (this, that, these, those) to identify and describe objects based on distance.
  2. Use there is and there are correctly to talk about the existence of singular and plural nouns.
  3. Identify singular and plural nouns, and use them correctly in simple sentences. You will also be able to use irregular plurals correctly and avoid common beginner mistakes regarding plurals.

Introduction: #

Today you will build essential language skills to describe things clearly and accurately, especially in situations like assisting customers over the phone. First, you will learn how to point out and describe items depending on how near or far they are from you or the caller, which is very useful when giving or confirming information about objects. Next, you will practice how to mention whether something exists or is available, using the correct structure for one item or multiple items. This will help you communicate details about products, services, or locations more effectively. Finally, you will work on recognizing the difference between one item and more than one, forming plural nouns correctly, including some special cases, and avoiding common mistakes. This will support you when giving clear and accurate information to customers.

Important terms (Vocabulary): #

Demonstrative Adjectives:

  • This: For a singular thing that is near you.
  • That: For a singular thing that is far from you.
  • These: For plural things near you.
  • Those: For plural things far from you.

Key Concepts (Grammar Rules): #

Demonstrative Adjectives: Demonstrative adjectives (this, that, these, those) are used to point to specific nouns and show:

  • Distance (near or far)
  • Number (singular or plural) They always go before a noun (person, animal or thing).

How to Use Them (Step by Step)

✔️ 1. Choose based on number #

Singular (one item): This / That

  • This phone
  • That building

Plural (more than one): These / Those

  • These shoes
  • Those boxes

✔️ 2. Choose based on distance #

Near (close to you): This / These

  • This document (in your hand)
  • These files (on your desk)

Far (not close): That / Those

  • That office (across the street)
  • Those products (in another location)

Basic Sentence Structures #

  1. Demonstrative + Noun + Verb + Complement This product is available. That option works better. These items are on sale. Those calls are recorded.
  2. Yes/No Questions Is this your account? Is that the correct address? Are these your details? Are those the correct documents?
  3. Short Answers Yes, it is. / No, it isn’t. Yes, they are. / No, they aren’t.
  4. With “be” for identification This is your confirmation number. That is the issue we discussed. These are your results. Those are the available plans.

Important Rules #

  1. Match singular and plural correctly This / That → singular noun These / Those → plural noun

There is vs. There are: #

“There is” and “there are” are used to talk about the existence of something, in other words, to say that something exists, is present, or is available.

👉 They answer the idea of: “What is there?” or “What can we find?”

Basic Structure #

✔️ There is (Singular): Use there is with one thing. #

Structure: There is + singular noun. Examples: There is a problem with your order. There is a new update available. There is a store near your location.

✔️ There are (Plural): Use there are with more than one thing. #

Structure:

  • There are + plural noun. Examples:
  • There are two options for your plan.
  • There are many restaurants in the area.
  • There are several issues with the account.

Negative Form #

To say something does NOT exist, use:

✔️ There is not (There isn’t) #

  • There isn’t a manager available right now.
  • There isn’t a charge on your account.

✔️ There are not (There aren’t) #

  • There aren’t any appointments today.
  • There aren’t enough details in the system.

Questions #

To ask if something exists, invert the structure:

❓ Is there…? (singular) #

  • Is there a solution to this issue?
  • Is there a supervisor available?

❓ Are there…? (plural) #

  • Are there any updates on my case?
  • Are there other options?

Important Tips (Very Useful for Students) #

  1. Match the noun, not the word “there”
    • There is a problem ✔️
    • There are problems ✔️
  2. Use “any” in questions and negatives
  • Are there any questions?
  • There aren’t any errors.
  1. Use contractions in speaking (very natural in call centers)
  • There’s = There is
  • There are → usually not contracted (avoid “there’re” for beginners)

📝 Summary: #

There is vs. There are:

  • There is – Only singular nouns. Example: These is an apple in my fridge.
  • There are – Only plural nouns. Example: There are many eggs in my fridge.

Demonstrative Adjectives Pro Tip: 👉 Think of it like this:

  • This / These = here
  • That / Those = over there

Plural Quick Tips:

  • Always check the last letter of the word
  • Listen for pronunciation (helps with -s vs -es)
  • Memorize irregular forms (no rule!)
